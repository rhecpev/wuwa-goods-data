JSON 생성

이 프로젝트의 picture 폴더를 읽어 series.json, goods.json, categories.json을 만듭니다. generate_json_folder2.py와 같은 규칙입니다. 문제를 확인한 뒤 저장하면 프로젝트 폴더의 JSON을 덮어씁니다.

  • 시리즈 폴더: picture/시리즈명_국가_날짜/
  • 대표 이미지: 시리즈 폴더 안의 mainTheme.*
  • 굿즈 파일: goods/캐릭터_카테고리_가격_메모.확장자 (캐릭터는 콤마로 여러 명, 메모는 생략 가능)
이 프로젝트의 picture 폴더를 읽습니다.

문제

picture 폴더를 검사해서 손봐야 할 파일을 모아 보여줍니다. 이미지를 누르면 원본이 열립니다.

세트로 묶기

체크한 굿즈를 구성품으로 하는 세트 대표 사진을 추가합니다. 캐릭터는 체크한 굿즈의 캐릭터를 모두 모아 넣고, 카테고리는 세트로 넣습니다. 체크한 굿즈의 메모는 세트 메모로 바뀝니다.
