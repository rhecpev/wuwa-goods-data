명조 굿즈 도감

JSON 생성

이 프로젝트의 picture 폴더를 읽어 series.json, goods.json, categories.json을 만듭니다. generate_json_folder2.py와 같은 규칙입니다. 문제를 확인한 뒤 저장하면 프로젝트 폴더의 JSON을 덮어씁니다.

  • 시리즈 폴더: picture/시리즈명_국가_날짜/
  • 대표 이미지: 시리즈 폴더 안의 mainTheme.*
  • 굿즈 파일: goods/캐릭터_카테고리_가격_메모.확장자 (캐릭터는 콤마로 여러 명, 메모는 생략 가능)
이 프로젝트의 picture 폴더를 읽습니다.

문제

picture 폴더를 검사해서 손봐야 할 파일을 모아 보여줍니다. 이미지를 누르면 원본이 열립니다.

시리즈·굿즈 추가

사진을 picture 폴더에 저장합니다. 저장하면 JSON 생성 탭으로 넘어가서 바뀌는 내용을 확인한 뒤 JSON에 반영합니다.

1

시리즈

이미 있는 시리즈를 고르거나, 목록 맨 위 "새 시리즈 만들기"로 새로 만듭니다.

2

굿즈 사진

파일명이 캐릭터_카테고리_가격_메모 형식이면 칸이 자동으로 채워집니다.

3

체크한 굿즈 한꺼번에 고치기

적은 칸만 바뀌고, 비워 둔 칸은 그대로입니다.

◆

세트로 묶기

체크한 굿즈를 구성품으로 묶습니다. 세트 캐릭터는 구성품 캐릭터로 자동으로 채워집니다.

4

굿즈 목록

⠿ 손잡이를 끌어 세트에 넣을 수 있습니다. 체크한 굿즈도 같이 옮겨집니다.

사진 합치기

가로·세로 칸 수를 정하고 사진을 칸에 끌어 놓아 모양을 잡으면, 그 모양 그대로 한 장으로 이어 붙입니다. 사진은 이 브라우저 안에서만 다룹니다.

배치

사진을 끌어 다른 칸에 놓으면 자리를 옮기고, 사진이 있던 칸이면 서로 바꿉니다. 빈 줄·빈 칸은 합칠 때 빠집니다.
