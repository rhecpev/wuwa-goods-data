# wuwa-goods-data

WuwaGoods 앱이 받아 가는 굿즈 데이터입니다. `도감 실행.bat`(또는 `python serve.py`)으로 편집 도구를 띄워 고칩니다.

## 굿즈 번호 (goodsUid)

`goods.json`의 굿즈마다 바뀌지 않는 번호 `goodsUid`가 붙어 있습니다. 앱은 이 번호로 같은 굿즈인지 판단하므로,
가격·메모·사진을 고쳐도 사용자의 보유·구매예정 기록이 그대로 남습니다.

- 번호는 `goods_ids.json`에 사진 경로별로 적혀 있습니다. **지우거나 직접 고치지 마세요.**
- JSON 생성 탭에서 저장하면 기존 굿즈는 원래 번호를, 새 굿즈는 다음 번호를 받습니다. 지운 굿즈의 번호는 다시 쓰지 않습니다.
- 굿즈 정보(파일명)는 **굿즈 탭이나 추가 탭에서** 고치세요. 번호가 새 파일명으로 옮겨집니다.
  탐색기에서 파일 이름을 직접 바꾸면 새 굿즈로 보고 새 번호를 받습니다.
- 올리기 탭은 푸시하기 전에 번호가 빠진 굿즈에 번호를 채웁니다(exe로 만든 `goods.json`을 넣은 경우 등).
  다른 git 도구로 직접 푸시하면 채워지지 않고, 번호가 빠진 데이터는 앱이 받지 않습니다.
- `goods.json`이 비어 있으면 저장·푸시하지 않습니다. 빈 목록이 올라가면 앱이 모든 굿즈를 지우려 하기 때문입니다.

`goodsId` 칸은 쓰지 않는 칸이라 항상 0입니다. 옛 버전 앱이 읽을 수 있어서 번호는 따로 `goodsUid`에 둡니다.
